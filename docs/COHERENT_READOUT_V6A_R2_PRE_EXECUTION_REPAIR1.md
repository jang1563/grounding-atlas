## Trigger

The first registered zero-forward plan was emitted at the canonical result
root and then subjected to the mandatory independent analyzer replay before
any behavioral command. Runner validation passed, but analyzer replay stopped
with `R2 planned record identity changed`.

The emitted root contained exactly four planning files and no attempt,
execution, record, analysis, or raw-logit artifact. Its plan manifest SHA-256
was `3642c02d7a15dfdfd88c1c0e08a06aa68c29c2c5e035450e860fccc3e6e354d4`.
The complete four-file root was moved without editing any file to:

```text
results/benchmark/single_cell/coherent_readout_v6a_r2_topology/qwen2.5-7b-instruct.quarantine-zero-forward-replay-fail-20260803-3642c02d
```

That retired root is permanently non-executable.

## Diagnosis

The seven-field identity itself was valid in all 2,304 rows. For every row,
the analyzer could reconstruct the identity from the prompt; the prompt and
cell stored identity echoes matched; all identities were unique; and the six
raw identity fields actually owned by both the prompt and cell matched.

The sole mismatch was `prompt_id`. It is generated by prompt rendering and is
therefore present in each prompt, while the corresponding planned cell stores
the resulting `record_identity_id` but does not redundantly copy `prompt_id`.
The synthetic analyzer replay fixture had copied full prompts into cells, so it
failed to represent this production structure. The analyzer then incorrectly
required all seven raw prompt fields to exist in the cell.

## Frozen correction

Repair 1 does not change the fixture, glyphs, rendered prompts, token IDs,
calls, stages, gates, estimands, seven-field identity definition, or execution
semantics. It changes only the independent analyzer check:

1. reconstruct the exact seven-field identity from the prompt, including
   `prompt_id`;
2. require both prompt and cell `record_identity_id` echoes to equal it; and
3. compare prompt and cell on the six fields both objects own:
   `block_call_index`, `cell_id`, `execution_block`, `execution_stage`,
   `global_call_index`, and `stage_call_index`.

Regression tests must model cells without `prompt_id` and reject drift in each
shared field, either identity echo, or the prompt `prompt_id`.
